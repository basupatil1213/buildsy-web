Buildsy — AI Project Idea Generator & Community

Overview
--------
Full-stack web application that helps developers generate personalized side-project ideas using AI and share them with a community platform.

Key features
------------
- AI-driven project idea generation
- Personal dashboard for managing project ideas
- Community feed with upvotes, comments, and collaboration
- Authentication and role-based features via Supabase

Tech stack
----------
React (Vite), Node.js (Express), Supabase (Postgres + Auth), OpenAI

Getting started
---------------
1. Install dependencies for frontend and backend
2. Configure environment variables (OpenAI, Supabase)
3. Start backend: npm run dev (in backend folder)
4. Start frontend: npm run dev (in frontend folder)

Notes
-----
See backend README for API endpoints and environment variables.
